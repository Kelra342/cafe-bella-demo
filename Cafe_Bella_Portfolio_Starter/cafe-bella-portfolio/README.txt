CAFE BELLA — PORTFOLIO CONCEPT WEBSITE
=====================================

This is a FICTIONAL brand and a real, functioning static website created as a personal portfolio demo.
It is NOT evidence of previous paid client work. The imagery comes from AI-generated Café Bella concept artwork.
Menu prices, business story, hours, and email address are fictional.

WHAT IS INCLUDED
- index.html (page content / sections)
- styles.css (design and mobile/tablet responsive layout)
- script.js (mobile menu, menu filters, current year)
- assets/ (local coffee/café images cropped from the original Café Bella concept artwork)

HOW TO RUN FOR FREE
1. Unzip this folder.
2. Double-click index.html — it opens in Chrome/Edge. Works offline, though Google Fonts need internet; fallback fonts are included.
3. Resize the browser window or press F12 and select a mobile viewport.
4. Test clicking Explore Menu, About, Gallery, Contact, and all four menu filter buttons.
5. On mobile width, click the hamburger menu, choose a link, and check that the menu closes.
6. Contact CTA opens your default email application; hello@cafebella.example is intentionally NOT a real address.

HOW TO HOST FOR FREE ON GITHUB PAGES
1. Create a FREE GitHub account (if you do not already have one).
2. Create a new PUBLIC repository called cafe-bella-demo.
3. Upload index.html, styles.css, script.js and the assets/ folder to the repository root.
4. Open Settings -> Pages -> Build and deployment -> Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. The website will become available at https://YOUR-USERNAME.github.io/cafe-bella-demo/ after deployment.
7. Check the real live link on a phone and laptop before adding it to your Fiverr portfolio.

IMPORTANT PORTFOLIO ETHICS
- Label the work "Café Bella — Personal Concept Website" or "Fictional Café Demo".
- Do not claim this is a completed job for an actual café.
- Do not say this supports actual payments, bookings, order checkout, SEO guarantees, or a database.
- The menu filter and navigation buttons work. The café email, address and prices are placeholders.
- A real client's website will require replacing all placeholder information and testing with that client's content.
